# Проверка подбора тарифов по этапам

Перед проверкой примените Prisma-схему и тестовые данные:

```bash
npm run prisma:push
npm run prisma:seed
```

Для каждого сценария вызовите `POST /calculator/find-tariff` с `stageType: "AUTO"` и проверьте результат.

| Расстояние | Вес | Ожидаемая цена | Ожидаемый тариф |
| --- | --- | --- | --- |
| 30 км | 15 000 кг | 10 065 RUB | Авто Калининград, 0–40 км / до 21 тонны |
| 30 км | 25 000 кг | 11 825 RUB | Авто Калининград, 0–40 км / более 21 тонны |
| 45 км | 15 000 кг | 11 495 RUB | Авто Калининград, 41–50 км / до 21 тонны |

Пример запроса:

```bash
curl -X POST http://localhost:9099/calculator/find-tariff -H "Content-Type: application/json" -d "{\"stageType\":\"AUTO\",\"distance\":30,\"weight\":15000,\"currency\":\"RUB\"}"
```

В интерфейсе откройте «Калькулятор», добавьте авто-этап «Калининград → Москва», укажите расстояние и вес, затем нажмите «Рассчитать». При недоступном API либо отсутствии подходящей строки стоимость этапа останется вычисленной fallback-формулой.
